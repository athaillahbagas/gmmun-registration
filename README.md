# GMMUN Registration Validation Pack

Dashboard berbahasa Indonesia untuk membantu pembahasan registrasi GMMUN dengan panitia dan hotel.

## Isi

- `index.html`: dashboard interaktif, tanpa dependensi eksternal.
- `GMMUN_Ringkasan_Registrasi.pdf`: ringkasan empat halaman.
- `GMMUN_Registration_Validation_Pack.pdf`: keputusan terbuka, audit perhitungan, draft alur, dan rencana uji.
- `GMMUN_Registration_Capacity.xlsx`: spreadsheet dengan input yang dapat diubah.

## Status analisis

Bahan diskusi dan pengujian, **belum SOP final atau keputusan penerapan**. Susunan 4 universal + 1 fleksibel + 1 exception tetap kandidat adaptif.

Informasi yang dilaporkan penyelenggara, asumsi pengujian, dan rekomendasi diberi label terpisah. Izin pendamping, jumlah petugas aktif, aturan rilis kunci, serta batas okupansi resmi masih memerlukan konfirmasi.

Perbandingan kapasitas memakai waktu dasar untuk setiap registrasi ditambah waktu tambahan kasus bantuan. Batas hitung ideal tidak sama dengan prediksi waktu tunggu atau jumlah orang di ruangan.

## Menjalankan

Buka `index.html` di browser atau gunakan GitHub Pages dari branch `main`, folder `/ (root)`. Semua unduhan memakai jalur relatif.
